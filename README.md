# 811 Ticket Tracker

A small offline-capable web app for tracking South Dakota 811 locate tickets: legal start dates, expirations (21 days), update deadlines and renewals.

- Open the GitHub Pages URL in Chrome on Android, then use **Install app** (or Chrome menu ⋮ → Add to Home screen).
- Tickets are stored only on the device (localStorage). Use **Backup → Export** to save a copy.
- Defaults follow SDCL 49-7A and ARSD 20:25; they are editable in Settings. Always go by the dates on your actual ticket.

No ticket data is stored in this repository.
